# Aideas
A place where I just put code of stuff I made with AI

## Projects

- [Still](Still/) — Immersive, mobile-first guided breathing for sleep, a busy mind, and anxiety. [▶ Open Still](https://antoinefortin.github.io/Aideas/Still/)

- [Cribbage](cribbage/) — Jeu de cribbage en français contre l’ordinateur, avec tuteur et pratique du compte. [▶ Jouer](https://antoinefortin.github.io/Aideas/cribbage/)

- [FeverLegacy](FeverLegacy/) — Immersive 3D exploration of Panic! At The Disco's *A Fever You Can't Sweat Out* (2005) and its cultural impact. Three.js. [▶ Run it](https://antoinefortin.github.io/Aideas/FeverLegacy/)
- [GlitchDrums](GlitchDrums/) — IDM/glitch drum machine: upload samples, per-step stutter, pitch, reverse, slice, bitcrusher, WAV export. [▶ Run it](https://antoinefortin.github.io/Aideas/GlitchDrums/)
- [MidiSketch](MidiSketch/) — Theory-driven MIDI arranger: pick a scale, build chord progressions, add bass and melody, preview and export MIDI. [▶ Run it](https://antoinefortin.github.io/Aideas/MidiSketch/)
- [TorrentDrop](TorrentDrop/) — Paste a magnet link or drop a .torrent, get direct download links. Pure browser, no server. [▶ Run it](https://antoinefortin.github.io/Aideas/TorrentDrop/)
- [GuitarTune](GuitarTune/) — Chromatic guitar tuner with 25+ tuning presets (emo, metal, jazz, open, 7-string). FFT pitch detection via mic, reference tones, gauge. [▶ Run it](https://antoinefortin.github.io/Aideas/GuitarTune/)
- [3DMathViz](3DMathViz/) — Interactive visual reference for 3D rendering math: vectors, matrices, transforms, projections, quaternions, coordinate spaces. Animated demos with live sliders. [▶ Run it](https://antoinefortin.github.io/Aideas/3DMathViz/)
- [PodTube](PodTube/) — Turn YouTube videos into a podcast RSS feed. Add videos, generate a feed URL, subscribe in any podcast app. No server. [▶ Run it](https://antoinefortin.github.io/Aideas/PodTube/)
- [SignPDF](SignPDF/) — Free PDF signer: open a PDF, draw or type your signature, add text/dates, download the signed PDF. Mobile-first, no server. [▶ Run it](https://antoinefortin.github.io/Aideas/SignPDF/)
- [SilenceCut](Silencer/) — Remove silence from audio recordings directly in your browser. No uploads, no server. [▶ Run it](https://antoinefortin.github.io/Aideas/Silencer/)
- [AudioDock](AudioDock/) — Windows C#/WPF app for batch-downloading YouTube audio as MP3 via yt-dlp and FFmpeg.
- [Tabtone](tabtone/) — One-click Chrome tab audio recorder with local MP3 encoding and automatic filenames.
- [Tabflow](tabflow/) — Per-tab equalizer, volume booster and local audio effects for Chrome.
- [three.js environment experiments](threejs-environment-experiments/) — interactive three.js scenes where something leaves a trace in its environment:
  - [Footfall](threejs-environment-experiments/footfall/) — vertex-displaced footprints in snow, sand or mud; scoops, packs and throws snowballs. [▶ Run it](https://antoinefortin.github.io/Aideas/threejs-environment-experiments/footfall/)
  - [Wake](threejs-environment-experiments/wake/) — wading through GPU-simulated water (bow wave, wake, stones, rain) with 12 water presets. [▶ Run it](https://antoinefortin.github.io/Aideas/threejs-environment-experiments/wake/)
  - [Splinter](threejs-environment-experiments/splinter/) — hyper-real PBR pump shotgun firing at a pine board: see-through pellet holes with end grain and exit tear-out, 3 ammo types. [▶ Run it](https://antoinefortin.github.io/Aideas/threejs-environment-experiments/splinter/)
