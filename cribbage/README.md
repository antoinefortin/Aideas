# Cribbage — l’école du jeu

[▶ Jouer dans le navigateur](https://antoinefortin.github.io/Aideas/cribbage/)

Jeu de cribbage en français contre l’ordinateur : règles intégrées, conseils et pratique du compte. Clique sur le paquet pour commencer.

Site entièrement statique, sans installation ni compilation. GitHub Pages le publie depuis la branche `main`, à l’adresse `/Aideas/cribbage/`. On peut aussi ouvrir `index.html` directement dans un navigateur.
