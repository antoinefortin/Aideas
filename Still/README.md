# Still — room to breathe

[▶ Open Still](https://antoinefortin.github.io/Aideas/Still/)

A mobile-first breathing experience for sleep, a busy mind, and anxiety. Five breathing patterns, an animated lake, optional ambient sound, dim mode, reduced motion, and timed sessions.

Entirely static: open `index.html` or serve this folder. No installation or build step. Research sources and limitations are included in the app. Google Fonts is optional; fallback fonts work offline.
